    Descripción

    Plataforma web para consultar el estado de una excavadora IoT, administrar demostraciones y desarrollar su control mediante una interfaz web.

    Tecnologías utilizadas

    HTML, CSS, JavaScript, Bootstrap, FastAPI, AWS, Amazon RDS, WebSocket y ESP32.

    Etapa actual

    Simulación local de movimientos, consulta autenticada al backend y visualización del estado registrado.
